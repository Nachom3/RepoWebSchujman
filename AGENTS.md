# AGENTS.md

Conventions and project-local context for AI agents working in this repo.

## Project skills

- `react-feature-architecture` (`.agents/skills/react-feature-architecture/SKILL.md`): Enforce strict feature-sliced React/Next.js architecture: one component per file, SOLID, feature folders.
- `typescript-advanced-types` (`.agents/skills/typescript-advanced-types/SKILL.md`): Master TypeScript's advanced type system including generics, conditional types, mapped types, template literals, and utility types.
- `tailwind-design-system` (`.agents/skills/tailwind-design-system/SKILL.md`): Build scalable design systems with Tailwind CSS v4, design tokens, component libraries, and responsive patterns.
- `react:components` (`.agents/skills/react-components/SKILL.md`): Converts Stitch designs into modular Vite and React components using system-level networking and AST-based validation.
- `prisma-migrate-discipline` (`.agents/skills/prisma-migrate-discipline/SKILL.md`): Enforce schema-first Prisma migration workflow on `backend/prisma/`. Triggers: edits to `schema.prisma`, `migrations/**`, `prisma migrate`, `db push`, `migrate deploy`.
- `backend-clean-architecture` (`.agents/skills/backend-clean-architecture/SKILL.md`): Move backend changes toward Clean/Hexagonal architecture. Triggers: backend, Express route, service, use case, repository, Prisma, controller.
